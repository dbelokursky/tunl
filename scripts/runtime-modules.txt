# JDK modules linked into the packaged runtime, read by the three packaging
# scripts so macOS, Windows and Linux can never ship different sets.
#
# Without --add-modules, jpackage hands jlink the JDK's default root set,
# which is every module that exports an API: ~290 MB of runtime for an app
# that touches a dozen modules.
#
# Adding a module is cheap; missing one is a crash the test suite cannot see,
# because the tests run on a full JDK. So the list is verified two ways
# before it changes: the whole test suite runs against an image built from
# exactly these modules, and scripts/verify-runtime-modules.sh — run by the
# test-linux leg of build.yml on every push and pull request — probes the
# capabilities that no test exercises (Russian locale data, EC/TLS, the
# Windows charsets).
#
# One module per line; everything after a '#' is a comment.
#
# Left out although jdeps lists them, because only code the app never runs
# refers to them (about 0.8 MB of every installer, 3 MB on disk):
#   java.naming  logback's JNDI features (ContextJNDISelector, insertFromJNDI,
#                SMTPAppender); logback.xml uses none of them.
#   jdk.jfr      JavaFX's JFR pulse logger. PulseLogger loads it by reflection
#                and catches NoClassDefFoundError, and it logs nothing unless
#                a flight recording is running; javafx.graphics requires the
#                module only statically.

java.base           # everything
java.desktop        # AWT tray icon, Dock icon, and all of JavaFX
java.logging        # slf4j/logback plumbing
java.management     # RuntimeMXBean (JvmLaunchCommand), JMX beans of the JVM
java.net.http       # every HTTP client in the app
java.scripting      # javax.script types FXMLLoader refers to
java.sql            # Jackson's java.sql handlers and logback's DBAppender refer to it
java.xml            # logback parses logback.xml with it
jdk.charsets        # windows-1251 and friends, needed on Windows consoles
jdk.httpserver      # com.sun.net.httpserver: the local MCP server
jdk.localedata      # Russian: without it the ru UI falls back to English data
jdk.unsupported     # sun.misc.Unsafe, still reached by some dependencies
jdk.zipfs           # jar:/zip: filesystems, used when reading the shaded jar
